Project Overview

This project demonstrates the planned workflow for deploying a Linux web server in Microsoft Azure. The design uses an Ubuntu virtual machine, Nginx to serve static files, a public IP address for web access, and a Network Security Group (NSG) to control inbound traffic.

Planned Azure Deployment Steps

  1. Create a dedicated Azure Resource Group.
  2. Create an Ubuntu Linux virtual machine and SSH key.
  3. Configure the network security group: allow HTTP TCP/80 for the public demo and restrict SSH TCP/22 to the administrator's IP.
  4. Connect to the VM over SSH and update the Ubuntu packages.
  5. Install Nginx and verify the service is running.
  6. Place the website files in /var/www/html/.
  7. Test the website using the VM's public IP address.
  8. Record screenshots and clean up the Azure resources after testing to avoid unwanted charges.

Status: Design and portfolio documentation prepared. Live Azure deployment: not yet performed.

Validation Checklist

  • ☐ VM is running (after actual deployment)
